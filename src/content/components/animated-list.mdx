A vertical list of cards with two states. Collapsed, only the first card (or the first `previewCount` cards) is visible at full size — the rest sit behind it with a slight scale-down and negative margin to suggest a stack. Tapping the toggle expands the stack into a normal vertical list with gap. Driven by a small inline script and CSS transitions.

## Slots

`<AnimatedList>` accepts a default slot of `<AnimatedListItem>` children.

`<AnimatedListItem>` accepts:

| Slot     | Purpose                                                             |
|----------|---------------------------------------------------------------------|
| `icon`   | Icon shown in the leading square. Use `<Icon name="lucide:..." />`. |
| default  | Extra content below `description` (a tag, timestamp, mini-action).  |

## Mechanism

- Each item carries a `--alist-stack-depth` CSS variable equal to its index (clamped to `visibleStackDepth`). Top card = `0`, second = `1`, etc.
- **Collapsed (`[data-expanded="false"]`):** the feed becomes `position: relative` with a measured `min-height`, and every item becomes `position: absolute; top: depth * peek` with `transform: scale(1 - depth * scaleStep)`. `z-index` decreases with depth so the top card paints on top and successive cards peek out the bottom.
- **Expanded (`[data-expanded="true"]`):** items return to normal flow with `gap`. Scale resets to `1`. The list reflows naturally.
- The collapsed feed height is computed once on init (and on resize) by reading the first card's natural height and adding `visibleStackDepth * peek` for the peek strips.
- The toggle is a real `<button>` with `aria-expanded` + `aria-controls` pointing at the feed's id. Hidden cards become focusable again on expand.
- If there are fewer items than `previewCount`, the toggle hides itself and all cards render expanded by default.

## Accessibility

- Container is `role="feed"` with `aria-label`, `aria-busy`, and `aria-expanded` (state mirrored on the toggle).
- Each item is `<article role="article" aria-roledescription="notification card">`, focusable so keyboard users can read each card.
- Toggle uses native `<button>` semantics — no `role="button"` workaround. `aria-expanded` flips on click.
- Items hidden in the collapsed view are `aria-hidden="true"` and removed from the tab order.
- `@media (prefers-reduced-motion: reduce)` cancels the transform/margin transitions; state still flips, just instantly.

## Theming

The component uses the project's semantic tokens directly — no hard-coded colors. Cards use `--color-panel` over `--color-stroke`, the toggle uses the `secondary`-style canvas surface, and everything flips automatically inside `[data-theme="dark"]`. Per the design rules, all surfaces are sharp rectangles (no `border-radius`).

## Notes

- Best at 3–6 cards. Too few makes the stack visual unconvincing; too many makes the collapsed silhouette unreadable.
- The toggle copy defaults to "Show more" / "Show less" but you can swap it via the `showMoreLabel` / `showLessLabel` props for context-specific phrasing ("View all alerts" / "Hide alerts").
- Cards beyond `previewCount` are still rendered in the DOM (so JS-disabled visitors can read them all). The collapse is a presentational layer.
