A bento grid of cards that reflows on hover. Hovering a card expands it horizontally, squeezes its row siblings, and reveals additional content (description + CTA). Hovering anywhere in a row also bumps that row taller, pushing other rows down. All driven by CSS — no JS.

## Slots

`<CardsBento>` and `<CardsBentoRow>` accept a default slot (rows or cards respectively).

`<CardsBentoCard>` accepts:

| Slot      | Purpose                                                                         |
|-----------|---------------------------------------------------------------------------------|
| `icon`    | Icon shown above the title. Use `<Icon name="lucide:..." />` for Lucide glyphs. |
| `image`   | Decorative background image/video that fills the card behind content.           |
| default   | Body content revealed on hover (description, list, etc.).                        |
| `cta`     | Action area at the bottom of the reveal — typically a `<Button>`.               |

Slot detection uses `Astro.slots.render()`, so omitted slots emit no markup.

## Mechanism

- The container is a vertical flex of rows; each row is a horizontal flex of cards. Cards default to `width: 100%` and share row width via flex distribution.
- **Card grow:** `:hover, :focus-within` on a card sets `width: var(--bento-grow-width)`. Because siblings have `width: 100%` and shrink, the row reflows and the active card dominates.
- **Row grow:** the same trick on `.bento-row` — `:hover, :focus-within` sets `height: var(--bento-grow-height)`, squeezing the other row.
- **Reveal:** body + CTA live in a wrapper using the `grid-template-rows: 0fr → 1fr` pattern with an `overflow: hidden` clip — animates from collapsed to natural height with no JS measurement.
- **Focus parity:** `:focus-within` mirrors hover so a keyboard user tabbing into the CTA gets the same expansion.
- **Reduced motion:** `@media (prefers-reduced-motion: reduce)` cancels transitions; reveal still works because grid-row state still flips, just instantly.

## Theming

Cards default to `theme="dark"` — `data-theme="dark"` on the card scopes the project's dark token values inside, so the card surface uses `var(--color-canvas)` (now dark) and text uses `var(--color-fg)` (now light). No hard-coded colors.

- Pass `theme="light"` to scope dark text on a light card.
- Pass `theme="inherit"` to follow the parent page theme — the card flips with the rest of the site.

All animation knobs are CSS custom properties on the bento root. Override per-instance with the props above or scope a new value in your own CSS:

```css
.my-bento {
  --bento-grow-width: 220%;
  --bento-grow-height: 140%;
  --bento-duration: 0.6s;
  --bento-gap: 1rem;
}
```

## Usage

```astro
---
import CardsBento from "@components/CardsBento.astro";
import CardsBentoRow from "@components/CardsBentoRow.astro";

---

<CardsBento>
  <CardsBentoRow>
    <CardsBentoCard title="Globe">
      <Icon slot="icon" name="lucide:globe" class="h-12 w-12" />
      <p>Description revealed on hover.</p>
      <Button slot="cta" label="Get Started" href="#" variant="secondary" />
    </CardsBentoCard>

    <CardsBentoCard title="With background">
      <img slot="image" src="/cover.jpg" alt="" />
      <Icon slot="icon" name="lucide:zap" class="h-12 w-12" />
      <p>Image fills the card behind content.</p>
    </CardsBentoCard>
  </CardsBentoRow>

  <CardsBentoRow>
    <CardsBentoCard title="Full-width row">
      <Icon slot="icon" name="lucide:shield" class="h-12 w-12" />
      <p>Single card in a row spans full width.</p>
    </CardsBentoCard>
  </CardsBentoRow>
</CardsBento>
```

## Notes

- Title is always visible. Body and CTA only show on hover/focus — keep the title self-explanatory so the card communicates without interaction.
- The image slot is `aria-hidden` and pointer-event-disabled — treat it as decorative.
- Best at 2–3 rows with 2–3 cards each. Many cards per row makes the squeeze too aggressive.
