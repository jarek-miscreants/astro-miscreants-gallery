## Notes

- **Theming.** Inner panel is wrapped in `data-theme="dark"` so text and buttons resolve to the dark palette regardless of page theme. The gradient overlay is hardcoded (`from-black/80 via-black/65 to-black/45`) so contrast is consistent across any image.
- **Image weight.** Bring images that work as backdrops, not headlines — landscape, atmospheric, low-detail. A busy product shot will fight the text.
- **Alt text.** Background images that don't carry information should have empty `imageAlt`. The text content already announces the section to screen readers.
- **One per page.** This component shouts. Pair it with calmer sections (banner, split callout) elsewhere on the same page.
