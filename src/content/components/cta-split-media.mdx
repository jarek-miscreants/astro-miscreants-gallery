## Notes

- **Composition.** Built from `SectionMain` and `Button`. The image is wrapped in a `border-stroke` panel so it sits inside the design system rather than floating against the canvas.
- **Aspect ratio.** Image renders at `aspect-[4/3]` and `object-cover`s — bring images that read at ~1200×900 or wider. Anything narrower will crop top/bottom.
- **Alt text.** Pass a real `imageAlt` if the image carries information. Leave it empty only when the image is purely decorative.
