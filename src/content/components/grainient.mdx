Animated grainy gradient rendered through a single GLSL fragment shader. A viewport-covering triangle is drawn into a WebGL2 canvas, and the shader does per-pixel rotational noise → sin-wave warp → three-color smoothstep blend → grain → contrast/gamma/saturation. Raw WebGL2, no external libraries.

## Preview

The component absolute-covers its (positioned) parent. Wrap it in a relatively-positioned container of any size you like and lay content over it.

## Layout contract

The component renders as `position: absolute; inset: 0` over its parent — same convention as `<img class="object-cover">` would have. The parent must be positioned (relative, absolute, fixed) for `inset: 0` to anchor correctly.

```astro
<div class="relative h-[60vh]">
  <Grainient />
  <div class="relative z-10 flex h-full items-center justify-center text-white">
    <h1>Hero</h1>
  </div>
</div>
```

## Mechanism

- Creates a `<canvas>` inside the wrapper, gets a `webgl2` context.
- Compiles `#version 300 es` vertex/fragment pair, links the program, sets up a single big triangle (`[-1,-1, 3,-1, -1,3]`) — cheaper than a quad and avoids the diagonal seam.
- All static props become uniforms set once at init. `iTime` and `iResolution` are updated each frame.
- `ResizeObserver` resizes the canvas in DPR-aware backing pixels (capped at 2× to control memory).
- `IntersectionObserver` pauses the rAF loop when the element is fully off-screen — important on long pages.

## Notes

- **WebGL2 required.** Falls through silently with a console warning if unavailable. WebGL2 is supported by every browser since 2022, but very old iOS devices may not have it.
- **No external dependencies.** Uses raw WebGL2 to keep the gallery dependency-free.
- DPR is capped at 2 to keep memory + fragment work reasonable; raise it in `setSize` if you need crisper grain on retina.
- For dark surfaces the defaults look good; on a light background, swap `color3` to a lighter shade or your palette's neutral.
